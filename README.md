## **About KNT.Dev**<br/>
For many local businesses and entrepreneurs, finding reliable, scalable, and modern digital solutions can be a fragmented process. 
The **KnT.Dev** website solves this by serving as a centralized, high-performance digital storefront. 
It clearly outlines our core technical capabilities—ranging from full-stack web applications to mobile development—and provides a direct, streamlined contact portal for clients to engage our services.

## **Why I Built It**<br/>
I built this platform to mark the evolution from KM CODES into a fully-fledged digital services agency alongside my co-founder, Tshepang. 
We needed a professional hub that not only catalogs our services but also acts as a live portfolio piece. 
By building it from the ground up, the site demonstrates our commitment to clean UI/UX principles, modern frontend architecture, and resilient software design.

## 🛠️ Tech Stack


**Framework:** React + TypeScript

**Build Tool:** Vite

**Styling:** Tailwind CSS (via PostCSS)

**Linting:** ESLint

**Hosting/Deployment:** Netlify (configured via _redirects for SPA routing)

## **How to Run It Locally**
Follow these steps to get the development environment running on your local machine:

*1. Clone the repository*

Bash
git clone https://github.com/km-codes23/knt-dev.git<br/>
cd knt-dev <br/>
*2. Install dependencies*

Bash
npm install<br/>
*3. Start the development server*

Bash
npm run dev<br/>
*4. View the application*<br/>
Open http://localhost:5173 (Vite's default port) in your browser to view the site.<br/>

*5. Build for production*
To test the production build locally before deploying:<br/>

Bash
npm run build
npm run preview
